# 🛍️ Website Catálogo

Um site catálogo dinâmico, responsivo e elegante desenvolvido para apresentar os produtos/serviços de [Nome da prima ou da loja].

---

## 📌 Sobre o Projeto

Este projeto foi construído para criar uma vitrine online interativa e acessível, permitindo que os clientes naveguem pelo catálogo de forma simples e intuitiva.

### ✨ Funcionalidades
- **Exibição Dinâmica de Produtos:** Layout organizado em cards com visualização clara dos itens.
- **Interatividade:** [Ex: Filtros por categoria / Busca de produtos / Modal de detalhes].
- **Design Responsivo:** Adaptado para telas de computadores, tablets e smartphones.
- **Navegação & Contato:** Links diretos para contato via WhatsApp e Instagram.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas.
- **CSS3:** Estilização, layout (Flexbox/Grid) e responsividade.
- **JavaScript (ES6+):** Manipulação do DOM, interatividade da interface e lógica do catálogo.
